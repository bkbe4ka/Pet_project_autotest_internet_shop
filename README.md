Шаблон автотеста
Тестовый сценарий: Переход с главной страницы в каталог, затем в разделе электроника выбор мониторов, фильтрация по нескольким пунктам, сортировка по наивысшему рейтингу, переход на карточку товара, добавление в корзину, переход в корзину, добавление в избранное, удаление из корзины, переход в избранное
Использованные инструменты: pytest, allure, selenium
